# Twin Maples — website

A fancy, modern one-page site for **Twin Maples** (senior care home) in **Jackson, Michigan**.

## Run it locally

From the `twin-maples/` folder:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173` in your browser.

## Customize

- Update copy and care offerings in `index.html`
- Replace sample images in the Gallery section with real photos
- Hook the “Schedule a Tour” form to a real email/CRM endpoint (it currently only previews the request)
